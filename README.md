# DefeatWatermarker

DefeatWatermarker is a defensive watermark and provenance robustness lab for evaluating how machine-readable AI provenance signals survive ordinary content transformations.

The project is intentionally designed as a **test harness, not a watermark-removal service**. It uses predefined, versioned mutation scenarios, separates mutation logic from detector feedback, and does not expose optimized "clean" artifacts.

Implementation is being developed on feature branches.
